# Multimodal Construction Intelligence Platform

## 📌 Project Overview

The **Multimodal Construction Intelligence Platform** is an AI-powered application designed to analyze construction-related information using multiple types of input, such as images, text, and documents. It helps users understand construction site conditions, identify potential issues, and generate useful insights using Artificial Intelligence.

The platform aims to make construction analysis easier, faster, and more organized through an interactive web interface.

## 🎯 Objectives

- Analyze construction-related images and text using AI.
- Identify potential construction issues and risks.
- Generate intelligent insights from user-provided inputs.
- Present analysis results in a simple and understandable format.
- Support better decision-making in construction projects.

## ✨ Key Features

- **Multimodal Input:** Supports relevant construction information through supported input types.
- **AI-Powered Analysis:** Uses an AI model to interpret submitted information.
- **Construction Intelligence:** Helps identify possible issues and observations.
- **Automated Reports:** Presents analysis results in a structured format.
- **Interactive Interface:** Provides a user-friendly way to submit inputs and view results.

## ⚙️ Installation and Setup

### Prerequisites

- Python installed on your system
- A Google Gemini API key, if required by the application
- Required Python packages listed in `requirements.txt`

### Steps

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project directory:

   ```bash
   cd Multimodal-Construction-Intelligence
   ```

3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Configure the required API key securely using environment variables or Streamlit secrets.

5. Run the application:

   ```bash
   streamlit run app.py
   ```

6. Open the local URL displayed in the terminal to access the application.

## 🔐 API Key Security

- Never upload API keys, passwords, or `.env` files containing secrets to a public repository.
- Store sensitive credentials using environment variables or Streamlit secrets.
- If a key is accidentally exposed, revoke it and generate a replacement.
